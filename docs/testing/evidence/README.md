# Evidence index (build of 10 September 2026, branch `claude/funny-brown-r7wpo9`)

Every file here was produced by running the commands listed against the code in this branch. **Provenance, taken from git rather than from memory:** artefacts are regenerated one at a time as the code they attest changes, so they do not share a single commit. `git log -1 -- docs/testing/evidence/<file>` is the authority for any given file, and is the only claim this page makes. Most of the set was produced at commit `d0bf6327ea646726b51d106ff190b42e62d7439a`; `remote-smoke-staging-rehearsal.txt`/`.json` at `86ebef8a71dc424dae292f7232b90cbb157562b0`; `test-results.txt`, `draw-bundle-W-2.json` and `draw-verify-W-2.txt` were regenerated after the branding and audit-fix work and are current for this tree. (Revisions of this page up to the round-two audit cited a pre-rebase hash that is not reachable from this branch at all; a delivery document that names a commit nobody can check out is worse than one that names none, so every hash on this page and in `docs/TEST_READINESS.md` / `docs/requirements-traceability.md` is now asserted to be an ancestor of HEAD by `test/fix-docs.test.mjs`.) Nothing is hand-edited except the redaction of temporary passwords in `seed-run.txt`. No file contains a secret value.
