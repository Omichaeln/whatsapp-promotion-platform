# Fixture guide

`fixtures/receipts/` — 40 synthetic JPEGs generated by `npm run fixtures` (`scripts/gen-fixtures.mjs`; deterministic, so regeneration is byte-stable). Everything is fictional: retailers (Sunrise Supermarket, Valuemart, Kwikshop Express), product (Goldcane Brown Sugar), purchases. `manifest.json` holds the labelled expectations used only by `bench/run.mjs` and tests; the pipeline never reads it.

Import templates: `fixtures/outlets-import-template.csv` (valid), `fixtures/outlets-import-invalid-example.csv` (duplicate code, missing code, bad dates).

Client receipts: keep a separately protected corpus (not in git), group copies of one transaction together, hold out a split untouched by parser tuning, and run `node bench/run.mjs` with a manifest of the same shape.
