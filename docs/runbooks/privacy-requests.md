# Privacy requests [support, platform_admin]

- Access: Participants → open → submissions/enrollments; export by an auditor if a document is needed (masked identity).
- Correction: support corrects name/surname/town (audited); phone change is a controlled staff action that never merges two participants.
- Withdrawal: marks consents and enrollments withdrawn; the participant can no longer enter.
- Deletion/anonymisation: platform_admin with a request reference; personal fields and the identity number are removed, ledger and audit references retained (legal-hold consideration for winners: agree with the client before anonymising a winner with an open claim).
- Retention (D-22 test values): raw receipts 90 days, extracted facts 180 days; audit chain append-only.
